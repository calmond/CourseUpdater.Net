# Contributing

Contributions are welcome.

Useful areas include:

- clearer instructor/student documentation;
- automated tests for the updater;
- improved diagnostics and recovery behavior;
- support for additional runtimes;
- Gradle/Java implementation;
- IntelliJ or other IDE integrations;
- examples from additional courses and disciplines.

Please keep the core design goals intact: predictable Git-based releases, safe failure behavior, project-specific configuration, and minimal student complexity.
